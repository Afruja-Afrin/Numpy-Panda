## 👋 About This Project
This repository contains **hands-on practice with NumPy and Pandas** using a **student information dataset** from my classmates (IIT-50, JU).  
The project focuses on **data cleaning, manipulation, and exploration**, preparing for **Machine Learning pipelines**.

---

## 🛠 Technologies Used
- **Python 3.13.5** – core language
- **NumPy** – numerical operations, arrays, vectorized computations, slicing, arithmetic, broadcasting, aggregations, filtering
- **Pandas** – series, dataframes, cleaning, selection, filtering, aggregations and transformations
- **VS Code** – for interactive coding and testing
